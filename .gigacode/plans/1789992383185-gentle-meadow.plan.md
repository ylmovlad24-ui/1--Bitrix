## Шаг 8. Убрать дублирование header/footer через JS

**Файл:** `bitrix/partials/header.html` — оставить только `<header>...</header>` + мобильное меню

**Файл:** `bitrix/partials/footer.html` — оставить только `<footer>...</footer>` + скрипты

**Файл:** `bitrix/js/main.js` — добавить загрузку партиалов:
```javascript
// Загрузка header
fetch('partials/header.html')
  .then(r => r.text())
  .then(html => {
    document.querySelector('head').insertAdjacentHTML('beforebegin', html);
  });

// Загрузка footer
fetch('partials/footer.html')
  .then(r => r.text())
  .then(html => {
    document.body.insertAdjacentHTML('beforeend', html);
  });
```

**Все HTML-файлы:** убрать `<header>...</header>` и `<footer>...</footer>`, оставить только `<main>...</main>` с контентом.

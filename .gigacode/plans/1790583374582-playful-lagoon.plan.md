### 2. CSS: Синтаксическая ошибка в media query

**Где:** `css/style.css`, строка ~716

**Проблема:**
```css
@media (max-width: 960px) {
  .platform-card { padding: 16px; }
  .platform-card__desc { font-size: 0.875rem; }
}

```

**Решение:** Переместить `.approach-grid > div` внутрь media query или убрать лишнюю скобку.

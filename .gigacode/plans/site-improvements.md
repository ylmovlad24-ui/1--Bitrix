# План улучшений сайта dianomi — фокус на конверсию

> **Принцип:** никаких изображений. Только текст, типографика, иконки, CSS-визуал.
> **Цель:** каждая страница должна подталкивать пользователя к действию (заявка/звонок).

---

## Улучшение 1: Усилить CTA на каждой странице (высокий приоритет)

### 1.1. Добавить «липкий» CTA-баннер на мобильных
**Файлы:** все `.html` + `css/style.css` + `js/main.js`

**Проблема:** На мобильных CTA виден только в шапке. При скролле пользователь теряет кнопку.

**Решение:** Фиксированная полоса внизу экрана на мобильных:
```
[ 📞 Позвонить ]  [ ✉ Оставить заявку ]
```
- Появляется при скролле > 500px
- Кнопка «Позвонить» → `tel:+79120767025`
- Кнопка «Оставить заявку» → скролл к форме на contacts.html

### 1.2. Добавить CTA-баннер на каждую секцию главной
**Файл:** `index.html`

**Проблема:** CTA-баннер только в конце страницы. Пользователь, не доскролливший до конца, не увидит призыв.

**Решение:** После каждой крупной секции — мини CTA:
- После «Проблемы» → «Знакомо? Получите консультацию»
- После «Как мы работаем» → «Начните с диагностики»
- После «Услуги» → «Обсудить ваш проект»

### 1.3. Добавить pop-up «Оставьте контаклы» с задержкой
**Файлы:** `js/main.js` + `css/style.css`

**Проблема:** Нет повторного захвата внимания.

**Решение:** Через 45 секунд на сайте — модальное окно:
```
Вам нужна помощь с выбором решения?
Консультация бесплатно — подберём оптимальное решение под ваш бюджет

[ Получить консультацию ]  [ Не сейчас ]
```
- Показывается один раз (localStorage)
- Кнопка скроллит на contacts.html или открывает форму

### 1.4. Добавить CTA прямо в карточки услуг
**Файлы:** `services.html`, `bitrix.html`, `bitrix24.html`

**Действие:** В каждой карточке услуги добавить кнопку «Обсудить проект» (не только заголовок-ссылку).

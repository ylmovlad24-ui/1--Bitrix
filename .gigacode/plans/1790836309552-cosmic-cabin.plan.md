# Анализ проекта Dianomi — Полный обзор

## 1. Общая информация

**Проект:** Сайт компании Dianomi — авторизованный партнёр 1С-Битрикс
**Локация:** г. Барнаул, Россия (проекты по всей России)
**Позиционирование:** Создание связанных цифровых систем (Битрикс24 + 1С-Битрикс + 1С)

## 2. Архитектура проекта

Проект существует в **двух версиях**:

### A. Статическая версия (HTML/CSS/JS)
- **Расположение:** Корень проекта (`C:/Users/Vlad/Documents/Ptodjec/1--Bitrix/`)
- **Технологии:** HTML5, CSS3 (переменные, Grid, Flexbox), Vanilla JS (ES5)
- **Структура:**
  - `index.html` — главная страница
  - `css/style.css` — дизайн-система (~1100 строк)
  - `js/main.js` — вся логика (~300 строк)
  - `partials/header.html` / `partials/footer.html` — переиспользуемые блоки
  - `img/` — изображения (SVG логотипы, OG-картинки)
  - ~19 HTML-страниц

### B. Bitrix-версия (для развёртывания на 1С-Битрикс)
- **Расположение:** `deploy/template_full/`
- **Шаблон:** `bitrix/templates/dianomi/`
- **Компоненты:** `bitrix/local/components/dianomi/` (8 кастомных)
- **Меню:** `bitrix/local/components/bitrix/menu/templates/megamenu/`
- **Формы:** `bitrix/local/components/bitrix/form/templates/project_form/`
- **Модуль:** `local/modules/dianomi/`

## 5. JavaScript-модули

1. **Mobile Menu** — бургер-меню, overlay, body scroll lock
2. **Mobile Dropdowns** — аккордеон для подменю
3. **Mega Menu** — hover на десктопе, click на мобильных
4. **Header Scroll** — тень при скролле
5. **Smooth Scroll** — якорные ссылки
6. **Project Form** — динамические поля, валидация, редирект на success.html
7. **FAQ Accordion** — раскрытие/скрытие
8. **Phone Mask** — маска +7
9. **Scroll Animations** — Intersection Observer
10. **Cookie Notice** — localStorage
11. **Counter Animation** — анимация чисел
12. **Current Year** — динамический год в футере

## 9. Архитектурные особенности

### Сильные стороны
- Чёткое разделение статической и Bitrix-версий
- Переиспользуемые компоненты в обоих вариантах
- D7 ORM вместо устаревшего CIBlockElement
- Mobile-first подход в CSS
- BEM-подобная нотация классов
- SEO-оптимизация (JSON-LD, OG, canonical)

### Замечания
- Header в статике и Bitrix версии слегка различаются (ссылки CTA)
- В статике CTA ведёт на `contacts.html`, в Bitrix — `contacts.php`
- Формы в статике ведут на `success.html`, в Bitrix — на `project.php`
- В футере статической версии нет ссылок на документы (privacy, personal-data)
- В `index.html` есть inline-стилей (~200 строк), которые можно вынести в CSS

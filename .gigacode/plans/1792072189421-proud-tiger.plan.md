# План: Базовый шаблон Битрикс для лендинга с включаемыми областями (дизайн Dianomi)

## Цель

Создать базовый шаблон сайта на 1С-Битрикс с включаемыми областями (widget regions) для лендинга, используя существующий дизайн Dianomi.

## Что такое включаемые области

В Битрикс — это **инклюды** (`$APPLICATION->IncludeArea()` / `$APPLICATION->IncludeRegion()`), которые позволяют администратору наполнять контент через визуальный редактор (Bitrix Admin Panel → Include Areas / Regions). Это альтернатива жёстко заданным компонентам в page-файлах.

## Архитектура

### Структура файлов шаблона

```
dianomi/bitrix/templates/dianomi/
├── .description.php          # Метаданные шаблона (обновить)
├── .style.php               # Настройки шаблона (обновить)
├── header.php               # DOCTYPE, head, навигация (обновить)
├── footer.php               # Footer, </body></html> (обновить)
├── template.php             # NEW: обёртка main + включаемые области
├── css/style.css            # Существующий дизайн Dianomi
├── js/main.js               # Существующий JS
├── img/                     # Существующие изображения
└── lang/ru/
    └── description.php      # NEW: языковые строки шаблона
```

### Включаемые области (регионы)

Создадим регионы в `template.php`:

| Регион | ID | Описание |
|--------|-----|----------|
| `dianomi.main.area` | Главная область (весь контент страницы) |
| `dianomi.header.region` | Верхняя часть header (до навигации) |
| `dianomi.footer.region` | Нижняя часть footer (перед копирайтом) |

Регионы определяются через `CAdminMessage` / `IncludeArea` и управляются через админку.

## Шаг 1: Обновить `.description.php`

**Файл:** `dianomi/bitrix/templates/dianomi/.description.php`

- Убедитьс��, что `NAME = "Dianomi"`
- Добавить `DESCRIPTION = "Базовый шаблон для лендингов с включаемыми областями"`
- Добавить `SORT = "10"`
- Добавить `TEMPLATE_TYPES` (если нужно несколько вариантов)

## Шаг 2: Обновить `.style.php`

**Файл:** `dianomi/bitrix/templates/dianomi/.style.php`

- Убедиться, что `CSS = Y`
- `COLOR_STYLE = S` (светлая тема)
- `PADDED_MAIN_PAGE = Y` (если нужно)

## Шаг 3: Обновить `header.php`

**Файл:** `dianomi/bitrix/templates/dianomi/header.php`

- Добавить регион включаемой области в начало body:
  ```php
  <?if(!defined("B_PROLOG_INCLUDED") || B_PROLOG_INCLUDED!==true)die();?>
  <?$APPLICATION->IncludeRegion("dianomi.header.region");?>
  <!DOCTYPE html>
  ...
  ```
- Сохранить всю существующую логику (меню, мобильное меню, meta-теги)

## Шаг 4: Обновить `footer.php`

**Файл:** `dianomi/bitrix/templates/dianomi/footer.php`

- Добавить регион включаемой области перед закрывающим тегом:
  ```php
  <?if(!defined("B_PROLOG_INCLUDED") || B_PROLOG_INCLUDED!==true)die();?>
  <?$APPLICATION->IncludeRegion("dianomi.footer.region");?>
  <footer class="footer">...</footer>
  ...
  </body>
  </html>
  ```

## Шаг 5: Создать `template.php`

**Файл:** `dianomi/bitrix/templates/dianomi/template.php` (NEW)

- Обёртка `<main id="main-content" class="main-content">`
- Включаемая область `dianomi.main.area`
- Пример:
  ```php
  <?if(!defined("B_PROLOG_INCLUDED") || B_PROLOG_INCLUDED!==true)die(); ?>
  <main id="main-content" class="main-content">
      <?$APPLICATION->IncludeArea($AR_AREA_CONTENT);?>
  </main>
  ```

## Шаг 6: Создать `lang/ru/description.php`

**Файл:** `dianomi/bitrix/templates/dianomi/lang/ru/description.php` (NEW)

- Языковые строки для шаблона:
  ```php
  <?
  return array(
      'TEMPLATE_NAME' => 'Dianomi Шаблон',
      'TEMPLATE_DESCRIPTION' => 'Базовый шаблон для лендингов с включаемыми областями',
      'TEMPLATE_HEADER' => 'Заголовок',
      'TEMPLATE_FOOTER' => 'Подвал',
      'TEMPLATE_MAIN' => 'Основной контент',
  );
  ?>
  ```

## Шаг 7: Обновить страницу-лендинг `index.php`

**Файл:** `dianomi/index.php`

- Показать пример использования включаемой области
- Показать, как компоненты вставляются в область
- Пример:
  ```php
  <?require($_SERVER["DOCUMENT_ROOT"]."/bitrix/header.php");
  $APPLICATION->SetTitle("Dianomi — Автоматизация бизнеса");
  ?>
  <?$APPLICATION->IncludeComponent("bitrix:main.include", "", array(
      "INCLUDE_ID" => "dianomi.main.area",
      "INCLUDE_AREA_COMPS" => "Y",
      "TEMPLATE_STYLE" => "default",
  ), false);?>
  <?require($_SERVER["DOCUMENT_ROOT"]."/bitrix/footer.php");?>
  ```

## Шаг 8: Настроить включаемые области в админке

- Через админку: **Настройки → Настройки продукта → Включаемые области**
- Создать области:
  - `dianomi.main.area` — «Главная область контента»
  - `dianomi.header.region` — «Область в header'е»
  - `dianomi.footer.region` — «Область в footer'е»

## Верификация

1. **Установка шаблона:** Загрузить файлы шаблона на сервер, в админке выбрать шаблон «Dianomi» для сайта
2. **Включаемые области:** В админке зайти в «Включаемые области» — убедиться, что 3 области видны и редактируемы
3. **Рендеринг:** Открыть страницу — проверить, что header, main, footer отображаются корректно с дизайном Dianomi
4. **Редактирование контента:** Через визуальный редактор добавить контент в включаемую область main.area
5. **CSS/JS:** Проверить, что `style.css` и `main.js` подключаются и работают

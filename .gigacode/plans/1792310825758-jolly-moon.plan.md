# План миграции HTML-прототипа dianomi в 1С-Битрикс

## Контекст

- **Проект:** Статический HTML-прототип сайта dianomi.ru (партнёр 1С-Битрикс, г. Барнаул)
- **Статус:** Нет установленного Bitrix в этой директории — файлы создаются как заготовка для копирования в DOCUMENT_ROOT действующего сервера рядом с существующим `/bitrix/`
- **Всего страниц:** 21 HTML-файл в корне
- **Ассеты:** 1 CSS (`css/style.css`), 1 JS (`js/main.js`), 3 SVG в `img/`
- **Header/Footer:** дублируются на каждой странице, нормализованные версии в `partials/header.html` и `partials/footer.html`

## Жёсткие запреты

- ❌ **НЕ создавать `/bitrix/local/`** — только `/local/` рядом с `/bitrix/`
- ❌ **НЕ редактировать файлы ядра** в `/bitrix/`
- ❌ **НЕ создавать кастомные компоненты** на первом этапе (только шаблон + публичные страницы)
- ❌ **НЕ класть страницы** внутрь `/local/templates/.../`
- ❌ **НЕ класть шаблон** внутрь `/local/components/`

## Этапы реализации

### Этап 1 — Шаблон сайта `/local/templates/main/`

#### 1.1 `description.php`
```php
<?php
return array(
    'NAME' => 'Dianomi (main)',
    'DESCRIPTION' => 'Кастомный шаблон сайта dianomi.ru',
    'VERSION' => '1.0',
    'TEMPLATE_CSS' => 'css/style.css',
    'IMAGE' => 'images/logo-dianomi.svg',
);
```

#### 1.2 `header.php` — ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ

```php
<?php
defined('B_PROLOG_INCLUDED') or die;

// === Подключение CSS через Asset API ===
$asset = \Bitrix\Main\Page\Asset::getInstance();
$asset->addCss(SITE_TEMPLATE_PATH . '/css/style.css');

// === Google Fonts ===
$asset->addString('<link rel="preconnect" href="https://fonts.googleapis.com">');
$asset->addString('<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>');
$asset->addString('<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;600;700&display=swap" rel="stylesheet">');

// === Подключение JS через Asset API ===
$asset->addJs(SITE_TEMPLATE_PATH . '/js/main.js');
```

**Структура `<head>`:**
```html
<head>
  <?php $APPLICATION->ShowHead(); ?>
  <title><?php $APPLICATION->ShowTitle(); ?></title>
</head>
```

**Сразу после `<body>`:**
```php
<?php $APPLICATION->ShowPanel(); ?>
```

**HTML шапки:** из `partials/header.html` — логотип, навигация, mega-menu, мобильное меню, бургер. Без уникального контента страниц. Все ссылки `href="*.html"` заменить на ЧПУ (`href="index.php"`, `href="/about/"` и т.д.).

#### 1.3 `footer.php` — ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ

**HTML подвала:** из `partials/footer.html` — бренд, колонки ссылок, копирайт. Все ссылки `href="*.html"` заменить на ЧПУ. Закрытие `</body></html>`.

#### 1.4 Ассеты шаблона

| Исходный путь | Путь в шаблоне |
|---|---|
| `css/style.css` | `/local/templates/main/css/style.css` |
| `js/main.js` | `/local/templates/main/js/main.js` |
| `img/logo-dianomi.svg` | `/local/templates/main/images/logo-dianomi.svg` |
| `img/logo-bitrix.svg` | `/local/templates/main/images/logo-bitrix.svg` |
| `img/logo-partner-badge.svg` | `/local/templates/main/images/logo-partner-badge.svg` |

**Пути в header.php/footer.php:** `img/` → `#SITE_TEMPLATE_PATH#/images/`

### Этап 2 — PHP-страницы (21 шт.)

Для каждой HTML-страницы:

1. Извлечь уникальный контент между header и footer (тег `<main>`)
2. Создать PHP-обёртку:
```php
<?php
require($_SERVER['DOCUMENT_ROOT'] . '/bitrix/header.php');
$APPLICATION->SetTitle('...');
?>
<!-- уникальный HTML этой страницы (без дублирования header/footer/html) -->
<?php require($_SERVER['DOCUMENT_ROOT'] . '/bitrix/footer.php');
```
3. **Страницы содержат ТОЛЬКО уникальный контент** — без дублей `<html>`, `<head>`, `<body>`, header, footer
4. Все внутренние ссылки с `.html` переписать на ЧПУ:
   - `href="about.html"` → `href="/about/"`
   - `href="contacts.html"` → `href="/contacts/"`
   - `href="index.html"` → `href="/index.php"`
   - `href="business-systems.html#solutions"` → `href="/business-systems/#solutions"`
5. Для `404.php` — добавить проверку:
```php
<?php
define("NO_KEEP_STATISTIC", true);
define("NO_AGENT_STATISTIC", true);
require($_SERVER['DOCUMENT_ROOT'] . '/bitrix/header.php');
// контент 404
require($_SERVER['DOCUMENT_ROOT'] . '/bitrix/footer.php');
```

## После заливки на сервер

1. **Назначить шаблон:** Админка → Настройки → Сайты → Шаблоны сайта → назначить шаблон `main` нужному сайту
2. **Проверить главную:** Открыть `/` — нет ошибок "is not a component", вёрстка шапки/подвала на месте
3. **Проверить внутренние:** Открыть 2–3 страницы (`/about/`, `/business-systems/`, `/integrations/`) — контент свой, шапка общая
4. **Проверить панель:** Войти в `/bitrix/admin/` — под админом видна панель (`$APPLICATION->ShowPanel()`)
5. **На проде:** `exception_handling.debug = false` в настройках сайта

```

├── .top.menu.php            → DOCUMENT_ROOT/.top.menu.php
├── index.php                → DOCUMENT_ROOT/index.php
├── about/index.php          → DOCUMENT_ROOT/about/index.php
├── ... (все 21 страница)     → ...
```

Файлы `bitrix/` и `upload/` на сервере уже существуют — их не трогаем.

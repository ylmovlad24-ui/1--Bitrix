## 1. ШАБЛОНЫ САЙТОВ

### Структура шаблона

**Основные файлы:**
- `header.php` — шапка сайта (логотип, меню, навигация)
- `footer.php` — подвал сайта (контакты, копирайт)
- `description.php` — название, описание, параметры шаблона
- `.styles.php` — стили для визуального редактора
- `template_styles.css` — стили каркаса сайта (шапка, подвал, сетка)
- `styles.css` — стили содержимого страницы (для визуального редактора)

**Папки:**
- `/components/` — шаблоны компонентов
- `/lang/` — языковые файлы
- `/page_templates/` — шаблоны страниц
- `/images/` — изображения шаблона

### Хранение шаблонов

- `/local/templates/<id>/` — пользовательские шаблоны (для разработки)
- `/bitrix/templates/<id>/` — системные шаблоны

**Приоритет:** `/local/templates/` > `/bitrix/templates/`

### Минимальный header.php

```php
<?php
if (!defined('B_PROLOG_INCLUDED') || B_PROLOG_INCLUDED !== true) die();
?>
<!DOCTYPE html>
<html lang="<?= htmlspecialcharsbx(LANGUAGE_ID) ?>">
<head>
    <?php $APPLICATION->ShowHead(); ?>
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title><?php $APPLICATION->ShowTitle(); ?></title>
</head>
<body>
    <div id="panel"><?php $APPLICATION->ShowPanel(); ?></div>
    <header class="site-header">
        <a href="<?= htmlspecialcharsbx(SITE_DIR) ?>">Главная</a>
    </header>
    <main>
        <h1><?php $APPLICATION->ShowTitle(false); ?></h1>
```

### Минимальный footer.php

```php
<?php
if (!defined('B_PROLOG_INCLUDED') || B_PROLOG_INCLUDED !== true) die();
?>
    </main>
    <footer class="site-footer">
        <p>Контактная информация</p>
    </footer>
</body>
</html>
```

### Файл страницы (index.php)

```php
<?php
require($_SERVER["DOCUMENT_ROOT"]."/bitrix/header.php");
$APPLICATION->SetTitle("Заголовок страницы");
?>

Контент страницы

<?php require($_SERVER["DOCUMENT_ROOT"]."/bitrix/footer.php"); ?>
```

### Константы и методы

| Константа/Метод | Назначение |
|---|---|
| `SITE_TEMPLATE_PATH` | Путь к папке шаблона от корня сайта (`/local/templates/demo`) |
| `SITE_DIR` | Путь к текущему сайту (многосайтовость) |
| `LANGUAGE_ID` | Текущий язык |
| `htmlspecialcharsbx()` | Экранирование для HTML |
| `$APPLICATION->ShowHead()` | Мета-теги, CSS, JS |
| `$APPLICATION->ShowPanel()` | Панель администратора |
| `$APPLICATION->ShowTitle()` | Заголовок `<title>` (с учётом свойства `title`) |
| `$APPLICATION->ShowTitle(false)` | Заголовок `<h1>` (только основной) |
| `$APPLICATION->SetTitle()` | Установить основной заголовок |
| `$APPLICATION->SetPageProperty()` | Установить свойство страницы |
| `Asset::getInstance()->addCss()` | Подключить CSS-файл |

### Рекомендации по созданию шаблона

1. Разделяйте header.php и footer.php заранее
2. Настраивайте стили до подключения к системе
3. Выделяйте повторяющиеся элементы
4. Для многоязычных сайтов используйте текстовые элементы
5. Планируйте место для компонентов
6. Отключите сжатие CSS/JS для отладки
7. Храните изображения в папке `images/`
8. Разделяйте CSS: `styles.css` (контент) и `template_styles.css` (шаблон)
9. Подключайте CSS через `Asset::getInstance()->addCss()`
10. **НЕ размещайте комплексные компоненты в header/footer** — это нарушает маршрутизацию

### Условия применения шаблона

- Без условия — шаблон по умолчанию
- Для папки или файла
- Для групп пользователей
- Период времени
- Параметр в URL
- Выражение PHP

### Проверка текущей страницы

- `$APPLICATION->GetCurPage(true)` — путь с `index.php`
- `$APPLICATION->GetCurPage(false)` — путь без `index.php`
- `$APPLICATION->GetCurDir()` — папка с завершающим слешем

## 2. ШАБЛОНЫ СТРАНИЦ

### Пассивный шаблон

PHP-файл с готовым содержимым. Содержит `header.php` и `footer.php`.

**Создание:**
1. Создать файл в `/local/templates/<id>/page_templates/`
2. Разместить код шаблона с `require(header.php)` и `require/footer.php)`
3. В `.content.php` добавить запись:

```php
$TEMPLATE['new.php'] = ['name' => 'Новый шаблон', 'sort' => 4];
```

### Активный шаблон

Шаблон с мастером создания страницы. Запрашивает параметры у контент-менеджера.

**Структура:**
- `template.php` — логика шаблона
- `/lang/` — языковые файлы
- `/images/` — изображения

**Класс шаблона:**

```php
<?php
class CMyPageTemplate
{
    function GetDescription() {
        return [
            "name" => Loc::getMessage("name"),
            "description" => Loc::getMessage("description"),
        ];
    }

    function GetFormHtml() {
        // HTML формы с вопросами
    }

    function GetContent($arParams) {
        // Генерация контента на основе ответов
    }
}
$pageTemplate = new CMyPageTemplate;
?>
```

## 3. ВКЛЮЧАЕМЫЕ ОБЛАСТИ

### Компонент `bitrix:main.include`

Позволяет контент-менеджеру редактировать фрагменты страницы.

**Параметры:**
- `AREA_FILE_SHOW` — `sect` (раздел), `page` (страница), `file` (из файла)
- `AREA_FILE_SUFFIX` — суффикс имени файла (по умолчанию `inc`)
- `AREA_FILE_RECURSIVE` — рекурсивный поиск (`Y`/`N`)
- `PATH` — путь к файлу области (для режима `file`)
- `EDIT_TEMPLATE` — шаблон при создании

**Пример:**

```php
<?php $APPLICATION->IncludeComponent(
    'bitrix:main.include',
    '',
    [
        'ENTITY_TYPE' => 'List',
        'IDS' => ['footer_brand'],
        'SET_FROM_CACHE' => 'Y',
        'CACHE_TYPE' => 'A',
        'CACHE_TIME' => '36000000',
        'EDIT_TEMPLATE' => '',
        'COMPONENT_TEMPLATE' => 'static',
        'ALLOW_FRAME' => 'Y',
    ]
);?>
```

**Альтернатива — `$APPLICATION->IncludeFile()`:**

```php
<?php $APPLICATION->IncludeFile('/include/contact.php'); ?>
```

## 4. МЕНЮ

### Типы меню

- **Статическое** — пункты добавляются вручную
- **Динамическое** — формируется из инфоблоков
- **Смешанное** — оба варианта

### Файлы меню

- `.тип.menu.php` — массив `$aMenuLinks`
- `.тип.menu_ext.php` — динамическое дополнение

### Массив `$aMenuLinks`

Каждый пункт — массив из 5 элементов:

```php
<?php
$aMenuLinks = [
    [
        "Название",           // 1. Текст пункта
        "page/",              // 2. Ссылка
        [],                   // 3. Доп. ссылки для подсветки
        [],                   // 4. Доп. параметры
        ""                    // 5. Условие отображения (PHP)
    ],
];
?>
```

### Компонент `bitrix:menu`

```php
<?php $APPLICATION->IncludeComponent(
    "bitrix:menu",
    "horizontal_dropdown",
    [
        "ALLOW_MULTI_SELECT" => "N",
        "CHECK_INTENSITY" => "N",
        "DELAY" => "N",
        "USE_EXT" => "Y",
        "MAX_LEVEL" => "1",
        "Children" => "Y",
        "SiteID" => "s1",
        "UseConfig" => "N",
    ],
    $componentData
);?>
```

**Параметры:**
- `MAX_LEVEL` — уровень вложенности (1-4)
- `Children` — выводить вложенные пункты (`Y`/`N`)
- `USE_EXT` — подключать `.menu_ext.php` (`Y`/`N`)

### Массив `$arResult` компонента

- `TEXT` — название пункта
- `LINK` — ссылка
- `SELECTED` — `true` если текущая страница
- `PERMISSION` — уровень доступа (`D`, `R`, `U`, `W`, `X`)
- `ITEM_TYPE` — тип ссылки (`D` — раздел, `P` — страница)
- `PARAMS` — дополнительные параметры

### Шаблоны меню

- `.default` — вертикальный
- `tree` — древовидный
- `vertical_multilevel` — вертикальное выпадающее
- `horizontal_multilevel` — горизонтальное выпадающее
- `grey_tabs`, `blue_tabs` — горизонтальные вкладки

### Компонент `bitrix:menu.sections`

Для динамического меню из разделов инфоблока.

## 5. СТИЛИ (CSS)

### Где хранить CSS

| Где хранится | Что оформляет | Файлы |
|---|---|---|
| Шаблон сайта | Каркас: шапка, подвал, сетка | `template_styles.css`, `styles.css` |
| Шаблон компонента | Разметка компонента | `style.css` |
| JS-расширение | Клиентский интерфейс | `config.php` |
| Страница | Только одна страница | `Asset::addCss()` |

### Разделение CSS

- `template_styles.css` — стили каркаса (шапка, подвал, сетка)
- `styles.css` — стили содержимого (для визуального редактора)

### Подключение CSS

```php
<?php
use Bitrix\Main\Page\Asset;

// D7-подход (рекомендуется)
Asset::getInstance()->addCss(SITE_TEMPLATE_PATH . '/styles/page.css');

// Классический подход
$APPLICATION->SetAdditionalCSS('/local/templates/demo/additional.css');
?>
```

### API подключения CSS

| API | Где использовать |
|---|---|
| `$APPLICATION->ShowCSS()` | В `header.php` внутри `<head>` |
| `$APPLICATION->SetAdditionalCSS()` | На странице или в коде |
| `Asset::getInstance()->addCss()` | D7-подход, точечное подключение |
| `Extension::load()` | JS-расширения |

### Оптимизация CSS

- Объединение CSS-файлов
- Подключение минифицированных версий
- Gzip-сжатие
- Результат в `/bitrix/cache/css/<SITE_ID>/<id>/`

## 6. ЗАГОЛОВКИ СТРАНИЦ

### Методы заголовков

| Метод | Назначение |
|---|---|
| `$APPLICATION->SetTitle()` | Установить основной заголовок |
| `$APPLICATION->SetPageProperty('title', ...)` | Установить заголовок окна браузера |
| `$APPLICATION->GetTitle()` | Получить основной заголовок |
| `$APPLICATION->GetTitle('title')` | Получить заголовок с учётом свойства `title` |
| `$APPLICATION->ShowTitle()` | Вывести заголовок `<title>` (с учётом свойства `title`) |
| `$APPLICATION->ShowTitle(false)` | Вывести основной заголовок `<h1>` |

### Пример использования

```php
<?php
$APPLICATION->SetTitle("О магазине");
$APPLICATION->SetPageProperty("title", "Магазин одежды Твой стиль");
?>
<!-- В header.php: -->
<title><?php $APPLICATION->ShowTitle(); ?></title>
<h1><?php $APPLICATION->ShowTitle(false); ?></h1>
```

## 8. КОМПОНЕНТЫ

### Подключение компонента

```php
<?php $APPLICATION->IncludeComponent(
    "bitrix:menu",
    "",
    $arParams,
    $componentData
);?>
```

**Параметры:**
- `CACHE_TIME` — время кэширования
- `CACHE_TYPE` — `A` (автоматически), `Y` (да), `N` (нет)
- `SET_TITLE` — устанавливать заголовок страницы

### Простые и комплексные компоненты

- **Простые** — выводят один элемент (новости, меню)
- **Комплексные** — полный рабочий процесс (каталог, корзина)

**ВАЖНО:** Комплексные компоненты размещать в рабочей области, НЕ в header/footer

### result_modifier.php

Модифицирует `$arResult` до шаблона.

### component_epilog.php

Выполняется ПОСЛЕ вывода компонента. Для подключения JS, мета-тегов.

## 9. ORM (D7)

### Концепция

- `\\Bitrix\\Main\\Entity\\DataManager` — класс-обёртка над таблицей БД
- Аннотации для описания структуры
- `\\Bitrix\\Main\\Entity\\DataObject` — объект

### Основные операции

```php
// Выборка
$result = User::getTable()->getList([
    'filter' => ['=ID' => 1],
    'select' => ['ID', 'NAME', 'EMAIL']
]);

// Добавление
User::add(['NAME' => 'Иван', 'EMAIL' => 'ivan@example.com']);

// Обновление
$user = User::getById(1)->fetch();
$user->set('NAME', 'Новое имя');
$user->save();

// Удаление
User::delete(1);
```

### Отношения

- `@relation` аннотации
- 1:N, 1:1, N:M
- `addTo()`, `removeFrom()`, `removeAll()`

## 13. СОБЫТИЯ

### Подписка на событие

```php
<?php
AddEventHandler("main", "OnBeforeProlog", "MyHandler");
?>
```

### Отписка

```php
<?php
RemoveEventHandler("main", "OnBeforeProlog", "MyHandler");
?>
```

### Основные события

- `OnBeforeProlog` — перед выводом страницы
- `OnAfterEpilog` — после вывода страницы
- `OnBeforeUserAuthorize` — перед авторизацией

# Чек-лист переноса проекта на 1С-Битрикс

## 1. Структура файлов

### 1.1. Core файлы
- [ ] `bitrix/header.php` — `require_once($_SERVER["DOCUMENT_ROOT"]."/bitrix/modules/main/include/prolog.php");`
- [ ] `bitrix/footer.php` — `require_once($_SERVER["DOCUMENT_ROOT"]."/bitrix/modules/main/include/epilog.php");`
- [ ] `index.php` — порядок: `header.php` → компоненты → `footer.php`
- [ ] `404.php` — корректная обработка 404

### 1.2. Шаблоны
- [ ] `bitrix/templates/{name}/header.php` — `SITE_TEMPLATE_PATH` вместо `/bitrix/templates/...`
- [ ] `bitrix/templates/{name}/footer.php` — `SITE_TEMPLATE_PATH`
- [ ] `bitrix/templates/{name}/.description.php` — регистрация шаблона
- [ ] `bitrix/templates/{name}/.style.php` — настройки (если нужны)
- [ ] Удалены дублирующие файлы (`.styles.php`, пустые CSS)

### 1.3. Компоненты
- [ ] `.description.php` — `'PATH' => array('NAME' => '...', 'FILE' => '')` (НЕ `'TEMPLATE'`)
- [ ] `template.style.css` — переименован из `style.css` (Bitrix загружает только его)
- [ ] `.parameters.php` — `Loc::loadMessages(__FILE__)` + `CACHE_SETTINGS`
- [ ] `class.php` — валидация входных данных, проверка прав
- [ ] `templates/.default/template.php` — корректная структура

## 2. Bitrix API — порядок вызовов

### 2.1. В template.php компонента
```php
<?if(!defined("B_PROLOG_INCLUDED") || B_PROLOG_INCLUDED!==true)die();?>
// 1. Проверка B_PROLOG_INCLUDED
// 2. Доступ к $arResult, $arParams
// 3. Вывод HTML
```

### 2.2. В шаблоне сайта (header.php)
```php
<?if(!defined("B_PROLOG_INCLUDED") || B_PROLOG_INCLUDED!==true)die();?>
// 1. Проверка B_PROLOG_INCLUDED
// 2. $APPLICATION->SetTitle()
// 3. DOCTYPE, head, meta
// 4. <?$APPLICATION->ShowPanel();?> — СРАЗУ после <body>
// 5. Контент
```

### 2.3. В index.php страницы
```php
<?require($_SERVER["DOCUMENT_ROOT"]."/bitrix/header.php");?>
// 1. $APPLICATION->SetTitle()
// 2. $APPLICATION->SetPageProperty()
// 3. $APPLICATION->IncludeComponent()
<?require($_SERVER["DOCUMENT_ROOT"]."/bitrix/footer.php");?>
```

## 3. Пути и ресурсы

### 3.1. Шаблонные пути
- [ ] `<?=SITE_TEMPLATE_PATH?>/` — для CSS, JS, img внутри шаблона
- [ ] `<?=CIBlock::GetID('CODE', 'SITE_ID')?>` — для инфоблоков
- [ ] `$_SERVER["DOCUMENT_ROOT"]` — для подключения core-файлов

### 3.2. Ссылки на страницы
- [ ] Относительные `/page.php` — работают для текущего сайта
- [ ] `<?=SITE_DIR?>` — для явного указания пути к сайту
- [ ] `<?=CPage::GetAbsolutePageURL()?>` — динамические URL

### 3.3. Медиа-ресурсы
- [ ] `/upload/` — файлы, загруженные через админку
- [ ] `/bitrix/templates/{name}/img/` — статика шаблона
- [ ] `/bitrix/templates/{name}/css/` — стили
- [ ] `/bitrix/templates/{name}/js/` — скрипты

## 6. Кэширование

### 6.1. Компоненты
- [ ] `CACHE_TYPE` — `A` (автоматически), `Y` (да), `N` (нет)
- [ ] `CACHE_TIME` — время кэша в секундах
- [ ] `CACHE_SETTINGS` — обязательный параметр в `.parameters.php`

### 6.2. Очистка
- [ ] Админка: Настройки → Настройки продукта → Кэш файлов → Очистить
- [ ] `php clear_cache.php` — скрипт очистки

## 7. Права и доступы

### 7.1. Файловые права (Linux)
- [ ] `bitrix/` — 755
- [ ] `bitrix/upload/` — 777 (если нужна запись)
- [ ] `bitrix/cache/` — 777 (если не используется БД)
- [ ] Файлы — 644

### 7.2. Права Bitrix
- [ ] Компоненты: доступ на чтение для всех
- [ ] Элементы инфоблоков: права на уровне инфоблока

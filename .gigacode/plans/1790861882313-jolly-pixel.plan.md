# Деплой Dianomi на Hostman (s277847.h1n.ru)

## Структура на сервере Hostman

```
/www/s277847.h1n.ru/
├── bitrix/                    ← Ядро Битрикс (уже установлено)
│   ├── header.php
│   ├── footer.php
│   ├── local/
│   │   ├── components/
│   │   │   └── dianomi/       ← Компоненты сайта
│   │   │       ├── hero/
│   │   │       ├── problems/
│   │   │       ├── solutions/
│   │   │       ├── before-after/
│   │   │       ├── approach/
│   │   │       ├── about-company/
│   │   │       ├── faq/
│   │   │       └── cta-form/
│   │   └── templates/
│   │       └── dianomi/       ← Шаблон сайта
│   └── ...
└── dianomi/                   ← Файлы сайта
    ├── index.php
    ├── about.php
    ├── contacts.php
    ├── css/
    ├── js/
    ├── img/
    └── ...
```

## Ключевые моменты

1. **Ядро Битрикс** уже установлено в `/www/s277847.h1n.ru/bitrix/`
2. **Компоненты** должны лежать в `/bitrix/local/components/dianomi/` (рядом с ядром)
3. **Шаблон** должен лежать в `/bitrix/templates/dianomi/` (рядом с ядром)
4. **Файлы сайта** лежат в `/dianomi/` (отдельная папка)
5. **Пути в PHP** используют `$_SERVER["DOCUMENT_ROOT"]` — автоматически корректны

## План действий

### Шаг 1: Создать архив 1 — "Ядро + Компоненты"

**Путь распаковки:** `/www/s277847.h1n.ru/`

**Содержимое архива:**
```
bitrix/local/components/dianomi/hero/           ← из dianomi-solution/components/dianomi/hero/
bitrix/local/components/dianomi/problems/       ← из dianomi-solution/components/dianomi/problems/
bitrix/local/components/dianomi/solutions/      ← из dianomi-solution/components/dianomi/solutions/
bitrix/local/components/dianomi/before-after/   ← из dianomi-solution/components/dianomi/before-after/
bitrix/local/components/dianomi/approach/       ← из dianomi-solution/components/dianomi/approach/
bitrix/local/components/dianomi/about-company/  ← из dianomi-solution/components/dianomi/about-company/
bitrix/local/components/dianomi/faq/            ← из dianomi-solution/components/dianomi/faq/
bitrix/local/components/dianomi/cta-form/       ← из dianomi-solution/components/dianomi/cta-form/
bitrix/templates/dianomi/                        ← из dianomi-solution/templates/dianomi/
```

**Файл:** `deploy/dianomi-core.zip`

### Шаг 2: Создать архив 2 — "Файлы сайта"

**Путь распаковки:** `/www/s277847.h1n.ru/dianomi/`

**Содержимое архива:**
```
index.php               ← из dianomi-solution/index.php
about.php               ← из dianomi-solution/about.php
contacts.php            ← из dianomi-solution/contacts.php
business-systems.php    ← из dianomi-solution/business-systems.php
bitrix24.php            ← из dianomi-solution/bitrix24.php
1c-bitrix.php           ← из dianomi-solution/1c-bitrix.php
web-systems.php         ← из dianomi-solution/web-systems.php
data-bi.php             ← из dianomi-solution/data-bi.php
project.php             ← из dianomi-solution/project.php
404.php                 ← из dianomi-solution/404.php
robots.txt              ← из dianomi-solution/robots.txt
sitemap.xml             ← из dianomi-solution/sitemap.xml
css/                    ← из dianomi-solution/css/
js/                     ← из dianomi-solution/js/
img/                    ← из dianomi-solution/img/
```

**Файл:** `deploy/dianomi-site.zip`

### Шаг 3: Проверка путей

Все PHP-файлы используют `$_SERVER["DOCUMENT_ROOT"]` — пути автоматически корректны:
- `require($_SERVER["DOCUMENT_ROOT"]."/bitrix/header.php");` → `/www/s277847.h1n.ru/bitrix/header.php`
- `require($_SERVER["DOCUMENT_ROOT"]."/bitrix/footer.php");` → `/www/s277847.h1n.ru/bitrix/footer.php`

### Шаг 4: Инструкция по деплою

Архивы уже созданы в `deploy/`:
- `dianomi-core.zip` — ядро + компоненты + шаблон
- `dianomi-site.zip` — файлы сайта

### Шаг 5: Инструкция по деплою

1. Загрузить `dianomi-core.zip` на сервер через файловый менеджер Hostman
2. Распаковать в `/www/s277847.h1n.ru/`
3. Загрузить `dianomi-site.zip` на сервер
4. Распаковать в `/www/s277847.h1n.ru/dianomi/`
5. Очистить кэш в админке Битрикс
6. Проверить работу компонентов

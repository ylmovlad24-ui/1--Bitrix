## Рекомендации Bitrix (официальные источники)

### 1. Структура файлов (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=36)
- **`/local/`** — только кастомные файлы (шаблоны, компоненты, PHP-код)
- **`/bitrix/`** — файлы ядра (НИКОГДА не редактировать!)
- **`/upload/`** — загруженные файлы (изображения, документы)
- **`/assets/`** — автоматически собираемые ресурсы (CSS/JS)
- **`/index.php`** — стартовая страница (обязательно должна существовать)

### 2. Компоненты (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=28)
- **Всегда использовать компоненты** для динамического контента
- **Кэширование:** `CACHE_TYPE = "A"` (авто), `CACHE_TIME = 3600` для статичных блоков
- **Параметры компонента:** выносить в `.parameters.php` для настройки в Админке
- **Временные файлы:** использовать `$_CACHE_DIR` для временных данных
- **Ошибка при отсутствии данных:** всегда проверять `if(!defined("B_PROLOG_INCLUDED") || B_PROLOG_INCLUDED!==true)die();`

### 3. Шаблоны компонентов (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=35)
- **Структура:** `components/bitrix/COMPONENT_NAME/templates/TEMPLATE_NAME/`
- **Множественные шаблоны:** один компонент может иметь несколько шаблонов
- **Языковые файлы:** `lang/ru/.parameters.php` и `lang/ru/template.php`
- **CSS шаблона:** подключается автоматически через `template_style.css`
- **JS шаблона:** подключается через `template.js` + `$APPLICATION->AddHeadScript()`

### 4. Инфоблоки (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=30)
- **Типы инфоблоков:**
  - `IBLOCK_CONTENT` — содержимое (статьи, новости)
  - `IBLOCK_NEWS` — новости
  - `IBLOCK_BIZPROC` — бизнес-процессы
  - `IBLOCK_LIST` — списки (меню, категории)
- **Свойства элементов:** использовать типы `STRING`, `TEXT`, `FILE`, `SECTION`, `USER_TYPE` (например, `IBLOCK_ELEMENT` для вложенности)
- **Работа с файлами:** всегда проверять `is_array($propertyValue)` для файловых свойств
- **ЧПУ для инфоблоков:** использовать `bitrix:news.detail` с ЧПУ `/news/#ELEMENT_ID#/`

### 5. Композит (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=40)
- **Включение:** `CMain::InitCompositeArray()` в `header.php`
- **Кеширование страниц:** в Админке → Страницы сайта → "Кешировать"
- **Проверка:** зелёная иконка в правом верхнем углу, блок `<!-- composite -->`
- **Производительность:** скорость < 0.5 сек для закэшированных страниц
- **Исключения:** динамические блоки (формы, поиск) не кэшируются

### 6. SEO (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=38)
- **Title:** `$APPLICATION->SetTitle("Уникальный title для каждой страницы")`
- **Description:** `$APPLICATION->SetPageProperty("description", "Уникальное описание")`
- **Keywords:** `$APPLICATION->SetPageProperty("keywords", "ключевые слова")`
- **Canonical:** `<link rel="canonical" href="<?=$APPLICATION->GetCurPage()?>">`
- **Open Graph:** `$APPLICATION->SetPageProperty("og:title", "OG Title")`
- **ЧПУ:** включить в Настройки → Настройки продукта → SEO-элементы
- **robots.txt:** в корне сайта, запретить индексацию `/admin/`, `/bitrix/`
- **sitemap.xml:** использовать компонент `bitrix:main.sitemap`

### 7. Безопасность (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=42)
- **Валидация данных:** всегда проверять и экранировать пользовательский ввод
- **CSRF-защита:** использовать `bitrix:form` (встроенная защита)
- **XSS-защита:** использовать `htmlspecialchars()` для вывода данных
- **Доступ к файлам:** запретить прямой доступ к `/local/` через `.htaccess`
- **Обновления:** регулярно обновлять ядро Bitrix
- **Пароли:** использовать сложные пароли для Админки
- **HTTPS:** обязательно включить SSL

### 8. Производительность (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=44)
- **Кеширование:** включить композит + кэширование страниц
- **CSS/JS:** минифицировать, объединять, подключать в `<head>`
- **Изображения:** использовать WebP, сжимать, указывать width/height
- **Шрифты:** использовать `font-display: swap` в CSS
- **Lazy loading:** `loading="lazy"` для изображений ниже первого экрана
- **Кэширование компонентов:** `CACHE_TIME = 3600` для статичных блоков
- **Индексы БД:** убедиться, что на полях поиска есть индексы

### 9. Адаптивность (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=46)
- **Mobile-first:** проектировать сначала для мобильных
- **Viewport:** `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- **Breakpoints:** использовать CSS-переменные для брейкпоинтов
- **Touch:** убедиться, что все элементы кликабельны на тач-устройствах
- **Тестирование:** Chrome DevTools → Device Toolbar

### 10. Доступность (a11y) (https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=48)
- **ARIA:** использовать `aria-label`, `aria-expanded`, `aria-hidden`
- **Навигация:** `skip-link` для перехода к контенту
- **Формы:** `label` для каждого поля, `required` атрибуты
- **Контраст:** минимальный контраст текста 4.5:1
- **Клавиатура:** все интерактивные элементы доступны с клавиатуры
- **Семантика:** использовать `<header>`, `<main>`, `<nav>`, `<section>`, `<footer>`

## Шаг 7: Официальные рекомендации Bitrix (Best Practices)

### 7.1 Структура файлов (официальные требования)

**Обязательно:**
- ✅ Кастомный код только в `/local/` — не в `/bitrix/`
- ✅ Шаблоны в `/local/templates/` — не в `/bitrix/templates/`
- ✅ Компоненты в `/local/components/` — не в `/bitrix/components/`
- ✅ PHP-код в `/local/php/` — не в `/bitrix/php/`

**Почему:** При обновлении Bitrix файлы в `/bitrix/` перезаписываются, в `/local/` сохраняются.

### 7.2 Разработка шаблона

**Обязательно:**
- ✅ `.description.php` — описание шаблона для Админки
- ✅ `.style.php` — настройки шаблона (CSS, цвета)
- ✅ `template.php` — обёртка контента с `$APPLICATION->ShowContent()`
- ✅ `header.php` начинается с `<?require($_SERVER["DOCUMENT_ROOT"]."/bitrix/header.php");?>`
- ✅ `footer.php` заканчивается `<?require($_SERVER["DOCUMENT_ROOT"]."/bitrix/footer.php");?>`

**Запрещено:**
- ❌ Править файлы в `/bitrix/templates/` — будут перезаписаны при обновлении

### 7.3 Разработка компонентов

**Обязательно:**
- ✅ Использовать `define("B_PROLOG_INCLUDED", true)` в начале каждого файла
- ✅ Кэширование через параметры компонента (`CACHE_TYPE`, `CACHE_TIME`)
- ✅ Проверка `$arResult` перед использованием
- ✅ Архивация данных в `$arResult` для передачи в шаблон

**Пример правильной структуры компонента:**
```php
<?if(!defined("B_PROLOG_INCLUDED") || B_PROLOG_INCLUDED!==true)die();

// Получение данных
$dbElements = CIBlockElement::GetList(...);
while($arElement = $dbElements->GetNext()) {
    $arResult[] = $arElement;
}

if(empty($arResult)) {
    return;
}

// Подключение CSS/JS компонента
$APPLICATION->addHeadScript('/local/components/dianomi/hero/script.js');
$APPLICATION->addHeadStyle('/local/components/dianomi/hero/style.css');
```

**Запрещено:**
- ❌ Прямой доступ к БД без через CDB* классы
- ❌ Использование `eval()` и `assert()`
- ❌ Вывод данных без `$APPLICATION->IncludeComponent()`

### 7.4 Кеширование и композит

**Обязательно:**
- ✅ Включить композитный режим для всех страниц
- ✅ Настроить кеширование компонентов (`CACHE_TYPE = "A"`)
- ✅ Кеширование страниц в Админке (3600 сек)
- ✅ Использовать `CACHE` параметры в `IncludeComponent()`

**Рекомендации:**
- Время жизни кеша: 3600 сек (1 час) для статического контента
- Для динамического: 60-300 сек
- Контролировать вывод: "Нет" (полное кеширование)

**Проверка:**
- Зелёная иконка композита в правом верхнем углу
- В исходном коде: `<!-- composite -->`
- Заголовок ответа: `X-Cache: hit`
- Время загрузки: < 0.5 сек

### 7.5 SEO-рекомендации

**Обязательно:**
- ✅ Уникальные title и description для каждой страницы
- ✅ Использование `$APPLICATION->SetTitle()` и `$APPLICATION->SetPageProperty('description')`
- ✅ Включение ЧПУ (полезных URL)
- ✅ robots.txt в корне сайта
- ✅ sitemap.xml в корне сайта

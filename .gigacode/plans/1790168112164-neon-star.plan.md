## CSS-классы для style.css

| Класс | Назначение |
|-------|-----------|
| `.service-detail__title` | Заголовок секции |
| `.service-detail__section` | Блок проблема/решение/результат |
| `.service-detail__label--problem` | Метка "Проблема:" |
| `.service-detail__label--solution` | Метка "Решение:" |
| `.service-detail__label--result` | Метка "Результат:" |
| `.service-detail__text` | Текст описания |
| `.service-included-list` | Список "Что входит" |
| `.service-included-list__check` | Галочка ✓ |
| `.service-detail-visual` | Декоративный блок |
| `.service-detail-visual--accent` | Оранжевый вариант |
| `.service-detail-visual--success` | Зелёный вариант |
| `.optimization-card` | Карточка оптимизации |
| `.optimization-card--primary` | Синяя обводка |
| `.optimization-card--accent` | Оранжевая обводка |
| `.accordion` | Контейнер аккордеона |
| `.accordion-item` | Элемент аккордеона |
| `.accordion-item--open` | Открытый элемент |
| `.accordion-header` | Заголовок аккордеона |
| `.accordion-body` | Тело аккордеона |
| `.accordion-body__content` | Контент тела |
| `.guarantee-card` | Карточка гарантии |
| `.guarantee-card__icon` | Иконка гарантии |
| `.guarantee-card__title` | Заголовок гарантии |
| `.guarantee-card__desc` | Описание гарантии |

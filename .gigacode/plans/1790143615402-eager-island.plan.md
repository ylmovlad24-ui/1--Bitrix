# План архитектуры «От общего к частному» для сайта dianomi

## Проблема
Сайт воспринимается как «массивный» и «без логики». Нарушен принцип постепенного погружения: пользователь попадает на страницу без контекста, видит дубли, перегруженные блоки и противоречивые данные (нули вместо цифр).

## Решение
Перестроить все страницы по принципу **от общего к частному**:
**Главная → Услуги → Конкретная услуга → Кейсы → О компании → Контакты**

---

## Логика навигации (User Flow)

```
Главная (index.html)
├── О компании (about.html) — «Кто мы?»
├── Услуги (services.html) — «Что предлагаем?»
│   ├── CRM Битрикс24 (bitrix24.html) — «Как внедряем?»
│   ├── Сайты на Битрикс (bitrix.html) — «Как разрабатываем?»
│   └── Оптимизация (services.html) — «Как улучшаем процессы?»
├── Кейсы (cases.html) — «Какой результат?»
├── Тарифы (editions.html) — «Сколько стоит?»
├── Блог (blog.html) — «Полезные материалы»
└── Контакты (contacts.html) — «Как начать?»
```

## Приёмы для улучшения восприятия

### 1. Визуальная иерархия
- H1 → 2.5rem, H2 → 2rem, H3 → 1.5rem, H4 → 1.25rem
- Подзаголовки секций → 1.125rem, color: text-muted
- Основной текст → 1rem, line-height: 1.7

### 2. Чередование фона
- Чередовать `white` и `bg-light` секции
- Это создаёт визуальные «островки» и облегчает сканирование

### 3. Whitespace
- Отступы между секциями: 80px (desktop), 48px (mobile)
- Отступы внутри карточек: 24px

### 4. CTA-кнопки
- На каждой секции — минимум 1 CTA
- Основные CTA → акцентный цвет
- Вторичные CTA → outline

### 5. Мобильная версия
- Sticky CTA (уже есть — оставить)
- Сворачиваемые блоки (FAQ, подробная форма)
- Карточки в 1 колонку

## Вдохновлено архитектурой amiveo.com

### Паттерны, которые нужно перенять:

1. **PAS-фреймворк (Problem-Agitate-Solution):** Боли → сразу после Hero, до предложения решений
2. **Dual CTA:** Два призыва на каждый блок — основной (модальное окно) + вторичный (ссылка на страницу)
3. **Цветовое кодирование карточек:** CSS-переменные (--card-color) для визуального различия блоков
4. **Cases Slider:** Горизонтальный слайдер (Swiper.js) вместо бесконечной сетки кейсов
5. **Сильный позиционирующий заголовок:** Не «Цифровая трансформация», а что-то вроде «Превратите хаос в систему»
6. **Модальные формы:** Все конверсии через попапы — пользователь не покидает страницу
7. **Mega-menu:** Вместо 7 пунктов меню — категории услуг с подкатегориями
8. **Anchor-навигация:** «О нас» в меню скроллит к секции `#about-us-anchor`

## Верификация

### Как тестировать:
1. **Первый экран:** Прочитать заголовок и подзаголовок за 3 секунды ✅
2. **Скролл:** Пройти по странице — каждый блок должен логически вытекать из предыдущего ✅
3. **Навигация:** Проверить, что breadcrumb отображается на всех внутренних страницах ✅
4. **Мобильная версия:** Открыть на телефоне — все CTA доступны тапом ✅
5. **Консистентность:** Проверить, что CTA ведут на логичные страницы ✅

### Метрики успеха:
- Увеличение времени на главной > 2 минут
- Уменьшение показателя отказов < 40%
- Увеличение кликов по CTA > 5%

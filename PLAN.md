## 1. ОБЩАЯ ИНФОРМАЦИЯ

**Компания:** dianomi  
**Сайт:** https://dianomi.ru/  
**Продукт:** 1С-Битрикс: Управление сайтом  
**Статус:** Авторизованный партнёр 1С-Битрикс  
**Цель:** Создать многостраничный статический прототип с последующей миграцией в 1С-Битрикс

### Проблемы текущего сайта (dianomi.ru):
1. Построен на Bitrix24 Landing — огромный DOM, тысячи inline-стилей, медленная загрузка
2. Нет чёткого CTA — нет кнопки «Оставить заявку» / «Получить консультацию»
3. Нет доверия — нет кейсов, отзывов, счётчиков
4. Нет информации о тарифах 1С-Битрикс — посетитель не понимает стоимость
5. Нет партнёрского статуса — не показано, что вы — официальный партнёр
6. Размытие SEO — навигация ведёт на разные поддомены (`tariff/`, `compan/`, `stati/`)
7. Плохие Core Web Vitals — много запросов к `js.bitrix24.ru`, `fonts.bitrix24.ru`

### Референс дизайна:
- **amiveo.com** — нравится логика многостраничного сайта, чистый дизайн, чёткая навигация

## 8. МИГРАЦИЯ В 1С-Битрикс (план на будущее)

### Шаг 1: Замена partials на Bitrix-компоненты
- `partials/header.html` → `bitrix:main.include` (шаблон `header`)
- `partials/footer.html` → `bitrix:main.include` (шаблон `footer`)
- Меню → `bitrix:menu` (компонент «Вертикальное меню»)

### Шаг 2: Конвертация страниц в Bitrix-шаблоны
- `index.html` → `.index.php` (шаблон главной)
- Остальные страницы → `.php` файлы

### Шаг 3: Интеграция форм
- Форма обратной связи → `bitrix:form` (публичная форма)
- Подключение CRM-лидов из Битрикс24

### Шаг 4: Composite технология
- Подключение Composite SDK от 1С-Битрикс
- Активация fragment caching

### Шаг 5: SEO и мета-теги
- `bitrix:main.meta` — автоматическая генерация мета-тегов
- `bitrix:breadcrumb` — хлебные крошки

## 10. ТРЕБОВАНИЯ К КАЧЕСТВУ

1. **Оригинальный дизайн** — никаких стандартных шаблонов Bitrix
2. **Mobile-first** — сайт оптимизирован для просмотра с телефона
3. **Быстрая загрузка** — минимум HTTP-запросов, оптимизированные изображения
4. **Доступность** — WCAG 2.1 AA (focus-visible, семантика, alt для изображений)
5. **Комментарии в коде** — подсказки для миграции в Bitrix (`<!-- MIGRATE: bitrix:menu -->`)
6. **Чистый код** — без фреймворков, без jQuery, чистый HTML/CSS/JS

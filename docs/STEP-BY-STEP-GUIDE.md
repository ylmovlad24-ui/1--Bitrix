> Загрузка через ZIP-архивы (FTP не нужен). Каждый шаг — конкретное действие.

## ЧТО МЫ ДЕЛАЕМ

1. Удаляем старые файлы компонентов и шаблона
2. Загружаем новые через ZIP-архивы

5. Проверяем что всё работает

## ШАГ 2. Загрузка через панель хостинга

### 2.1. Зайди в панель хостинга

1. Открой браузер
2. Перейди в панель хостинга (туда же, где управляешь сайтом)
3. Найди свой сайт `s277847.h1n.ru`
4. Нажми **Файловый менеджер** (или "Управление файлами")

### 2.2. Удаление старых компонентов

1. В файловом менеджере перейди в папку: `bitrix/local/components/`
2. Если папка `dianomi` уже существует — удали её:
   - Нажми правой кнопкой на `dianomi` → **Удалить**
   - Подтверди удаление

### 2.3. Загрузка компонентов

1. В той же папке `bitrix/local/components/` нажми **Загрузить** (или "Загрузить файлы")
2. Выбери файл `components-dianomi.zip` с рабочего стола
3. Нажми **Загрузить**
4. После загрузки нажми **Распаковать** (или "Извлечь")
5. Укажи папку: `dianomi/` (или оставь пустым — распакуется в текущую)
6. Подтверди распаковку
7. Удали файл `components-dianomi.zip` (он больше не нужен)

> Проверь: в `bitrix/local/components/dianomi/` должно быть 8 папок

### 2.4. Удаление старого шаблона

1. Перейди в папку: `bitrix/templates/`
2. Если папка `dianomi` уже существует — удали её
3. Подтверди удаление

### 2.5. Загрузка шаблона

1. В папке `bitrix/templates/` нажми **Загрузить**
2. Выбери файл `template-dianomi.zip`
3. Нажми **Загрузить**
4. Распакуй архив
5. Удали `template-dianomi.zip`

> Проверь: в `bitrix/templates/dianomi/` должны быть `header.php`, `footer.php`, `template.php`, `css/`, `js/`, `img/`

### 2.6. Удаление старых страниц

1. Перейди в корень сайта `/`
2. Если файлы `index.php`, `about.php`, `contacts.php` и другие уже есть — удали их все
3. Подтверди удаление

> **Важно:** Не удаляй папки `bitrix/`, `upload/` и другие системные файлы

### 2.7. Загрузка страниц

1. В корне сайта `/` нажми **Загрузить**
2. Выбери файл `pages-dianomi.zip`
3. Нажми **Загрузить**
4. Распакуй архив
5. Удали `pages-dianomi.zip`

> Проверь: в корне сайта должны быть все `.php` файлы

1. В админке: **Контент** → **Инфоблоки**

3. Нажми **Создать тип инфоблока**
4. Заполни:

| Поле | Что вписать |
|------|-------------|
| **Тип инфоблока (код)** | `information_pages` |
| **Название** | `Страницы сайта` |

## ШАГ 7. Для нового сайта (expertiza и др.)

Когда будешь делать новый сайт:

1. **Создай папку** сайта на сервере (например `expertiza/`)
2. **Скопируй** все `.php` файлы из `dianomi/` в `expertiza/`
3. **Скопируй** компоненты: `bitrix/local/components/dianomi` → `bitrix/local/components/expertiza`
4. **Скопируй** шаблон: `bitrix/templates/dianomi` → `bitrix/templates/expertiza`
5. **Привяжи** шаблон `expertiza` к сайту в админке

## ЧТО ДЕЛАТЬ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Сайт не открывается

1. Проверь что файлы загружены через файловый менеджер
2. Проверь что архивы были распакованы

### Компоненты не отображаются

1. Очисти кэш (ШАГ 6.1)
2. Проверь что в `bitrix/local/components/dianomi/` есть 8 папок

### Инфоблоки не найдены

1. Проверь коды инфоблоков — они должны быть точно: `page_hero`, `page_problems`, `page_solutions`, `page_before_after`, `page_approach`, `page_about`, `page_faq`
2. Проверь что элементы активны

### Ошибки PHP

1. **Настройки** → **Настройки продукта** → **Настройки модулей** → **main**
2. Поставь галочку "Включить режим отладки"
3. Посмотри текст ошибки — покажет файл и строку

# Пошаговая инструкция по развёртыванию Dianomi на Bitrix

> Эта инструкция для тех, кто делает всё впервые. Каждый шаг — конкретное действие.

---

## ЧТО МЫ ДЕЛАЕМ

У нас есть готовый сайт на Bitrix. Нам нужно:
1. Загрузить компоненты и шаблон сайта на сервер
2. Создать инфоблоки и заполнить их данными
3. Привязать шаблон к сайту
4. Проверить что всё работает

---

## ШАГ 1. Загрузка файлов на сервер

### 1.1. Загрузка компонентов

**Что загружать:** Папку `bitrix/local/components/dianomi`

**Откуда:** `C:\Users\Анна\IdeaProjects\bitrix\s277847.h1n.ru\bitrix\local\components\dianomi`

**Куда:** На сервер в папку `s277847.h1n.ru/bitrix/local/components/`

**Как:**
1. Открой FTP-клиент (FileZilla или любой другой)
2. Подключись к серверу своего хостинга
3. Найди папку `bitrix/local/components/` сайта `s277847.h1n.ru`
4. Скопируй туда папку `dianomi` целиком

> Внутри должны быть 8 папок: `about-company`, `approach`, `before-after`, `cta-form`, `faq`, `hero`, `problems`, `solutions`

### 1.2. Загрузка шаблона сайта

**Что загружать:** Папку `bitrix/templates/dianomi`

**Откуда:** `C:\Users\Анна\IdeaProjects\bitrix\s277847.h1n.ru\bitrix\templates\dianomi`

**Куда:** На сервер в папку `s277847.h1n.ru/bitrix/templates/`

**Как:**
1. В том же FTP-клиенте найди папку `bitrix/templates/`
2. Скопируй туда папку `dianomi` целиком

> Внутри должны быть: `header.php`, `footer.php`, `template.php`, папки `css/`, `js/`, `img/`

### 1.3. Загрузка файлов страниц

**Что загружать:** Все `.php` файлы из `dianomi/`

**Откуда:** `C:\Users\Анна\IdeaProjects\bitrix\s277847.h1n.ru\dianomi`

**Куда:** В корень сайта `s277847.h1n.ru/`

**Как:**
1. В FTP-клиенте открой корень сайта
2. Скопируй все файлы: `index.php`, `about.php`, `contacts.php`, `business-systems.php`, `bitrix24.php`, `bitrix24-prices.php`, `web-systems.php`, `1c-bitrix.php`, `1c-bitrix-prices.php`, `data-bi.php`, `project.php`, `robots.txt`, `sitemap.xml`

### 1.4. Проверка core-файлов

Убедись что эти файлы есть в корне `bitrix/`:

| Файл | Где должен быть |
|------|----------------|
| `header.php` | `s277847.h1n.ru/bitrix/header.php` |
| `footer.php` | `s277847.h1n.ru/bitrix/footer.php` |

> Они уже должны быть на сервере. Проверь что они содержат:
> - `header.php` → `require_once($_SERVER["DOCUMENT_ROOT"]."/bitrix/modules/main/include/prolog.php");`
> - `footer.php` → `require_once($_SERVER["DOCUMENT_ROOT"]."/bitrix/modules/main/include/epilog.php");`

## ШАГ 2. Привязка шаблона к сайту

### 2.1. Зайди в админку Bitrix

1. Открой браузер
2. Перейди по адресу: `https://s277847.h1n.ru/bitrix/admin/`
3. Введи логин и пароль от админки
4. Нажми "Войти"

### 2.2. Зайди в настройки шаблонов

1. В левом меню нажми: **Настройки**
2. В подразделе найди: **Настройки продукта**
3. Нажми: **Шаблоны сайтов**

### 2.3. Выбери свой сайт

1. В списке сайтов найди `s277847.h1n.ru`
2. Нажми на него
3. В поле **Шаблон** выбери `dianomi` из выпадающего списка
4. Нажми кнопку **Сохранить** внизу страницы

> Готово! Шаблон `dianomi` привязан к сайту.

1. В админке нажми: **Контент** → **Инфоблоки**

3. Нажми кнопку **Создать тип инфоблока** (или "Добавить")
4. Заполни поля:

| Поле | Что вписать |
|------|-------------|
| **Тип инфоблока (код)** | `information_pages` |
| **Название** | `Страницы сайта` |

5. Нажми **Сохранить**

### 3.2. Создание инфоблока `page_hero`

1. В левом меню нажми: **Контент** → **Инфоблоки**
2. Нажми кнопку **Создать инфоблок**
3. Заполни поля:

| Поле | Что вписать |
|------|-------------|
| **Тип инфоблока** | `Страницы сайта` (выбери из списка) |
| **Код** | `page_hero` |
| **Название** | `Hero Section` |
| **Сортировка** | `10` |

4. Нажми **Сохранить**

5. Теперь создай свойства. В открывшемся окне или в списке инфоблоков найди `page_hero` → нажми **Свойства** → **Добавить свойство**

Создай каждое свойство отдельно:

| № | Код | Название | Тип | Множественное |
|---|-----|----------|-----|--------------|
| 1 | `BADGE_TEXT` | Текст бейджа | Строка (S) | Нет |
| 2 | `TITLE` | Заголовок | Строка (S) | Нет |
| 3 | `DESCRIPTION` | Описание | Строка (S) | Нет |
| 4 | `COUNTER_1` | Счётчик 1 | Строка (S) | Нет |
| 5 | `COUNTER_2` | Счётчик 2 | Строка (S) | Нет |
| 6 | `COUNTER_3` | Счётчик 3 | Строка (S) | Нет |
| 7 | `COUNTER_LABEL_1` | Подпись счётчика 1 | Строка (S) | Нет |
| 8 | `COUNTER_LABEL_2` | Подпись счётчика 2 | Строка (S) | Нет |
| 9 | `COUNTER_LABEL_3` | Подпись счётчика 3 | Строка (S) | Нет |
| 10 | `BENEFITS_LIST` | Преимущества | Строка (S) | **Да** |

> **Как создать свойство:**
> 1. Нажми "Добавить свойство"
> 2. В поле **Код** впиши код из таблицы
> 3. В поле **Название** впиши название
> 4. **Тип** выбери "Строка (S)"
> 5. **Множествен��ое** — если "Да", поставь галочку
> 6. Нажми **Сохранить**

## ШАГ 7. Для нового сайта (например, expertiza)

Когда будешь делать новый сайт:

### 7.1. Создай папку сайта

На сервере создай папку: `expertiza/`

### 7.2. Скопируй страницы

Скопируй все `.php` файлы из `dianomi/` в `expertiza/`:
- `index.php`
- `about.php`
- `contacts.php`
- и т.д.

### 7.3. Создай компоненты для expertiza

Скопируй папку `bitrix/local/components/dianomi` в `bitrix/local/components/expertiza`

### 7.4. Создай шаблон для expertiza

Скопируй папку `bitrix/templates/dianomi` в `bitrix/templates/expertiza`

### 7.5. Привяжи шаблон

В админке: **Настройки** → **Шаблоны сайтов** → выбери сайт `expertiza` → шаблон `expertiza`

## ЧТО ДЕЛАТЬ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Сайт не открывается

1. Проверь что файлы загружены на сервер
2. Проверь права доступа (должны быть 644 для файлов, 755 для папок)

### Компоненты не отображаются

1. Очисти кэш: **Настройки** → **Кэш** → **Очистить**
2. Проверь что компоненты загружены в `bitrix/local/components/dianomi/`
3. Проверь что шаблон привязан к сайту

### Инфоблоки не найдены

1. Проверь что инфоблоки созданы с правильными кодами
2. Проверь что элементы созданы и активны (статус "Активный")

### Ошибки PHP

1. Включи режим отладки: **Настройки** → **Настройки продукта** → **Настройки модулей** → **main** → поставь галочку "Включить режим отладки"
2. Посмотри текст ошибки — обычно указывает на конкретный файл и строку

# Dianomi — Документация проекта

## 📋 О проекте

**Название:** Dianomi — интегратор связанных цифровых систем  
**Платформа:** Статический HTML/CSS/JS сайт  
**Дата создания:** 2026-09-24  
**Версия:** 1.0

---

## 🎯 Позиционирование

> «Создавать связанные цифровые системы, в которых процессы, сотрудники, клиенты и данные работают как единое целое»

**Ключевые продукты:**
- **Битрикс24** — CRM, корпоративный портал, процессы, совместная работа
- **1С-Битрикс** — корпоративные сайты, интернет-магазины, B2B-порталы

## 🔧 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — переменные, Grid, Flexbox, media queries
- **JavaScript** — ES5 (без фреймворков)
- **Шрифты:** Inter (Google Fonts)
- **Иконки:** Emoji (📞, ✉️, 📍)

---

## 📱 Адаптивность

**Media queries:**
- `600px` — мобильные устройства
- `960px` — планшеты
- `1200px` — десктоп

**Mobile-first подход:** Базовые стили для мобильных, расширение для десктопа.

## 🎨 Дизайн-система

**Цветовая палитра:**
- `--primary: #2A5B9A` — основной синий
- `--accent: #E67E22` — акцентный оранжевый
- `--bg: #F8F9FA` — фон
- `--text: #2D3142` — текст

**Типографика:**
- Шрифт: Inter
- Базовый размер: 16px
- Line-height: 1.5-1.7

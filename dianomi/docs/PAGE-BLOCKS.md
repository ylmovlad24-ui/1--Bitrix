## 🎯 Общие паттерны

### Структура большинства страниц

```
1. Page Hero (H1 + Subtitle + CTA)
2. Секция 1 (H2 + Content)
3. Секция 2 (H2 + Content)
4. Секция 3 (H2 + Content)
5. CTA Section (H2 + Description + Button)
```

### CTA-элементы

| Элемент | Ссылка | Где используется |
|---------|--------|------------------|
| «Обсудить проект» | `/project.html` | Все страницы |
| «Обсудить внедрение» | `/project.html` | Битрикс24 |
| «Обсудить веб-проект» | `/project.html` | 1С-Битрикс |
| «Сравнить тарифы» | `/bitrix24-prices.html` | Битрикс24 |
| «На главную» | `/index.html` | 404, success |

### Типы секций

| Тип | CSS-класс | Описание |
|-----|-----------|----------|
| Обычная | `.section` | Базовая секция |
| Альтернативная | `.section--alt` | Секция с фоном |
| CTA | `.cta-section` | Финальный призыв к действию |
| Hero | `.page-hero` | Первый экран страницы |
